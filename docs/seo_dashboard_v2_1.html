🔥 Phase 1 — Fix Critical (Chi tiết từng bước)

#1 — Thêm Security Headers
⏱ 15 phút  |  👤 Dev
Vấn đề: Thiếu X-XSS-Protection và Content-Security-Policy → site dễ bị tấn công XSS

Cách làm: Mở file .htaccess (gốc WordPress), thêm đoạn sau vào cuối file:
# Security Headers - Thêm vào cuối .htaccess <IfModule mod_headers.c> Header always set X-XSS-Protection "1; mode=block" Header always set Content-Security-Policy "default-src 'self' https: 'unsafe-inline' 'unsafe-eval'; img-src 'self' https: data:; font-src 'self' https: data:;" Header always set Referrer-Policy "strict-origin-when-cross-origin" Header always set Permissions-Policy "camera=(), microphone=(), geolocation=()" </IfModule>
✅ Kết quả: Security headers từ 2/4 → 4/4. Google đánh giá site an toàn hơn.
#2 — Thêm H1 cho Homepage
⏱ 5 phút  |  👤 Content/Dev
Vấn đề: Trang chủ mangthanhcong.vn không có thẻ H1 → Google không hiểu topic chính của site

Cách làm: Vào WP Admin → Appearance → Customize → Homepage, thêm H1:
<h1>Mạng Thành Công - Cung Cấp Thiết Bị Mạng, Cáp Quang, Tủ Rack Chính Hãng</h1> Nếu không muốn hiển thị to trên giao diện, thêm CSS: <style> .homepage-h1 { font-size: 24px; text-align: center; margin: 20px 0; } </style>
✅ Kết quả: Google hiểu ngay topic chính. Keyword "thiết bị mạng", "cáp quang", "tủ rack" được nhấn mạnh.
#3 — Fix Title/Meta cho trang "tủ điện 150x200" (đang gần Top 1!)
⏱ 15 phút  |  👤 SEO
Vấn đề: Keyword "tủ điện 150x200" đang rank position 2.3 với 18 impressions. Title hiện tại chưa tối ưu → fix title có thể lên top 1.

Cách làm: WP Admin → Products → tìm sản phẩm tủ điện 150x200 → sửa Yoast/RankMath:
TITLE CŨ: (chưa biết chính xác, cần check) TITLE MỚI: Tủ Điện 150x200 - Tủ Điện Kín IP65 Giá Tốt Nhất 2026 | TCNET META MỚI: Tủ điện 150x200mm chính hãng, chống bụi IP65, thép sơn tĩnh điện. Giá từ xxx.000đ, giao hàng toàn quốc. Hotline: [số ĐT]
✅ Kết quả expect: Position 2.3 → Top 1 trong 1-2 tuần. CTR tăng từ 5.56% → 15-25%
#4 — Fix Title cho "tủ rack 3u" (đang position 5.1)
⏱ 15 phút  |  👤 SEO

TITLE MỚI: Tủ Rack 3U - Tủ Mạng Mini 3U Treo Tường Giá Rẻ | TCNET META MỚI: Tủ rack 3U chất lượng cao, thiết kế nhỏ gọn treo tường. Phù hợp văn phòng, cửa hàng. Giá từ xxx.000đ, bảo hành 12 tháng. Đặt hàng ngay!
✅ Kết quả expect: Position 5.1 → Top 3 trong 2-3 tuần. CTR tăng gấp đôi.
#5 — Thêm Internal Links từ bài "cách kiểm tra cáp quang" (đang Top 1!)
⏱ 20 phút  |  👤 Content
Vấn đề: Bài blog "cách kiểm tra cáp quang bị đứt" đang rank Top 1 (pos 1.2) → đây là trang mạnh nhất site nhưng chưa tận dụng để đẩy sản phẩm.

Cách làm: Mở WP Admin → Posts → tìm bài "cách kiểm tra cáp quang" → thêm 3-5 link vào nội dung:
Thêm các link sau vào bài viết (chèn tự nhiên trong nội dung): 1. "...sử dụng <a href="/san-pham/may-han-quang-fujikura/">máy hàn quang Fujikura</a> để hàn nối..." 2. "...kiểm tra bằng <a href="/san-pham/otdr-may-do-cap-quang/">máy đo OTDR</a> để xác định vị trí đứt..." 3. "...thay thế bằng <a href="/danh-muc/cap-quang/">cáp quang chính hãng</a> đảm bảo chất lượng..." 4. "...kết nối với <a href="/san-pham/odf-12fo-rack-mount/">ODF quang 12FO</a> tại tủ phân phối..." 5. "Xem thêm: <a href="/blogs/cap-quang-4fo-8fo-12fo/">Phân biệt cáp quang 4FO, 8FO, 12FO</a>"
✅ Kết quả: Link juice từ trang Top 1 chảy xuống 5 trang sản phẩm → đẩy ranking sản phẩm lên. Đồng thời giảm bounce rate vì user click sang sản phẩm.
#6 — Xóa 9 Plugins Inactive + Files Public
⏱ 10 phút  |  👤 Dev
Cách làm:
Bước 1: WP Admin → Plugins → chọn tất cả plugin Inactive → Delete Bước 2: Xóa file public qua FTP hoặc File Manager: - Xóa: /readme.html - Xóa: /wp-admin/install.php (KHÔNG xóa nếu site chưa cài xong) Bước 3: Chặn REST API user list, thêm vào functions.php: add_filter('rest_endpoints', function($endpoints) { if (isset($endpoints['/wp/v2/users'])) { unset($endpoints['/wp/v2/users']); } if (isset($endpoints['/wp/v2/users/(?P<id>[\\d]+)'])) { unset($endpoints['/wp/v2/users/(?P<id>[\\d]+)']); } return $endpoints; });
✅ Kết quả: Giảm attack surface, tăng tốc load, WordPress Health score tăng.
#7 — NOINDEX 423 trang Thin Content <100 từ
⏱ 2 giờ  |  👤 SEO/Dev
Vấn đề: 423 trang có <100 từ, chỉ có tên sản phẩm + giá, không có giá trị SEO → lãng phí crawl budget

Cách làm (dùng Yoast/RankMath):
CÁCH 1 — Thủ công (cho vài chục trang): WP Admin → Products → mở từng sản phẩm → Yoast → Advanced → "Allow search engines to show this page?" → No CÁCH 2 — Hàng loạt bằng SQL (cho 423 trang, cần backup trước): -- Lấy danh sách từ file thin_content_action_plan.csv (cột action = NOINDEX) -- Import vào plugin "Search & Replace" hoặc chạy SQL CÁCH 3 — Dùng plugin: Cài "Jeanne's NOINDEX Manager" → upload CSV danh sách URLs → apply NOINDEX hàng loạt
⚠️ Lưu ý: Làm tối đa 50 trang/tuần. Không NOINDEX hết cùng lúc. Ưu tiên NOINDEX trang 0 traffic trước (check GSC).
#8 — Fix 39 trang 404 → Redirect 301
⏱ 1 giờ  |  👤 Dev/SEO
Cách làm: Dùng plugin Redirection hoặc .htaccess:
# Mẫu redirect trong .htaccess (thêm trước # END WordPress): Redirect 301 /san-pham/old-product-name/ https://mangthanhcong.vn/san-pham/new-product-name/ # Hoặc dùng plugin Redirection: WP Admin → Tools → Redirection → Add New Source URL: /san-pham/old-url/ Target URL: /san-pham/correct-url/ Group: Redirections → Add Redirect # Danh sách 39 URLs 404 xem trong file: broken_links.csv
