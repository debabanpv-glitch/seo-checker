🏗️ Tab 4: Sức Mạnh SEO (SEO Strength)

MỚI — HIGHLIGHT

Focus: Nền tảng SEO đang mạnh hay yếu? Xây đến đâu rồi?

🔗 Backlink Profile

  • Tổng backlinks, sống/chết ratio
  • DR/UR distribution chart
  • Mới build tuần này (Notion + Ahrefs)
  • Đối thủ comparison (Notion Competitor DB)

  • Cluster Coverage — bao nhiêu topic đã phủ

  • Content Gaps — topic nào chưa có bài
  • Entity map visualization (clusters → pages → KW)

🔍 Onpage & Technical

  • 6 category scores (content/technical/images/links/eeat/ai)
  • Pending fixes count (Notion tasks)
  • Score trend (lần audit trước vs giờ)

🔗 Internal Link Strength

  • Pillar ↔ Cluster coverage — % pages linked to pillar
  • Orphan pages — trang không có internal link vào
  • Cross-cluster links — liên kết giữa các topic
  • Anchor text health — over-optimization check

Data: Backlinks DB + Topical Map + SEO Audit + Notion (đã có phần lớn, cần gộp view)

⚡ 8. Phương Án Triển Khai — Bắt Đầu Từ Đâu?

🅰️ Phương án A: Từ ngoài vào (Recommend)

Làm Dashboard V2 trước, dùng data local đã có. Sync Notion/Sheets sau.

  • Bước 1: Dashboard V2 với 4 tabs — dùng data GSC + KW + Audit + Backlinks + Topical Map (đã có hết)
  • Bước 2: Thêm Sync Engine (Notion + Sheets) → bổ sung data vào Dashboard
  • Bước 3: Client Report generator
Ưu điểm: Có kết quả ngay, dùng được luôn. Sync Notion/Sheets chỉ là "thêm data" chứ không chặn việc dùng.
Nhược: Tab Thực Thi sẽ chưa có data AI/Người cho đến khi sync xong.

🅱️ Phương án B: Từ trong ra

Làm Sync Engine trước, rồi mới build Dashboard.

  • Bước 1: Sync Notion + Sheets → SQLite
  • Bước 2: Dashboard V2 (có đủ data từ đầu)
  • Bước 3: Client Report
Ưu điểm: Dashboard ra đời với đủ data ngay.
Nhược: Phải setup Notion API key, debug sync trước khi thấy kết quả. Chậm hơn có visual output.

🔤 10. Từ Khóa 2 Bộ

📌 Bộ Cam Kết (KW Hợp đồng)

Từ khóa cam kết với khách hàng trong hợp đồng.

  • Có thể không có trong GSC (chưa có traffic hoặc vị trí quá thấp)
  • Mục đích: báo cáo top cho khách + tự theo dõi tiến độ
  • Đã có is_tracked = true flag trong DB keyword_rankings (~510 KW)
  • Dùng cho: trang báo cáo khách hàng, export, Telegram summary
Hiện tại: is_tracked flag đã có trong DB. Cần UI hiển thị rõ ràng bộ này riêng.

🌐 Bộ Tự Follow (KW Semantic)

Từ khóa theo topic, bổ sung semantic SEO.

  • Track theo topical map / cluster — mỗi cluster có bộ KW riêng
  • Mục đích: mở rộng topical authority, phủ semantic
  • Mở rộng liên tục khi nghiên cứu thêm KW mới
  • Không cần báo cáo khách — dùng nội bộ để ra quyết định content
Hiện tại: Nằm trong topic_cluster_keywords. Cần liên kết với keyword_rankings.

📊 11. Google Analytics

Hiện tại không có MCP/tool trực tiếp cho GA4. 2 lựa chọn:

Option A: GA4 Reporting API

Cần service account JSON key từ Google Cloud.

  • Build service riêng: google-analytics.service.ts
  • Lấy được: sessions, bounce rate, conversions, page views
  • Cron tự động — không cần mở Claude session
  • Setup phức tạp hơn (IAM, API enable, key)

Option B: Dùng GSC (đã có)

GSC đã đủ cho hầu hết traffic metrics.

  • Clicks, impressions, CTR, avg position — đầy đủ
  • Không cần setup thêm gì
  • Thiếu: sessions từ direct/social, bounce rate, conversions
  • Phù hợp với giai đoạn hiện tại (SEO-focused)
Khuyến nghị: Start với GSC (Option B) — đã có data, không cần setup thêm. Thêm GA4 sau nếu cần conversion tracking hoặc multi-channel analysis.
