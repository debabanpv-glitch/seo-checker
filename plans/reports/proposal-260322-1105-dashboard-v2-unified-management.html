📋 4. Phân Chia Tab Dashboard V2

📊 Tab 1: Tổng quan

MỚI
  • KPI Cards — tasks xong, content publish, KW top10, backlinks (gộp từ tất cả nguồn)
  • Activity Feed — timeline hoạt động gần đây, tag nguồn (AI/Tự viết/Auto)
  • Tiến độ dự án — 3 project bars, % completion, so sánh target
  • Báo cáo tuần — auto-gen, 1-click copy/gửi Telegram/xuất HTML

📝 Tab 2: Nội dung

CẢI TIẾN
  • Gộp 2 nguồn: AI (Notion Content DB) + Tự viết (Google Sheets)
  • Tag nguồn: mỗi bài hiển thị "AI" hoặc "Tự viết"
  • Giữ nguyên: calendar view, member stats, project filter
  • Thêm: content gap alert (so target tháng)

🔍 Tab 3: SEO

CẢI TIẾN
  • Giữ nguyên: KPI, keyword distribution, traffic trend, project cards
  • Thêm: Notion Competitor Analysis data (nếu có)
  • Thêm: Notion Backlink Tracker tổng hợp
  • Strategy roadmap giữ nguyên

📋 Tab 4: Công việc

MỚI
  • Notion Task Tracker sync → hiển thị tất cả tasks
  • Filter: Dự án, Danh mục, Trạng thái, Người thực hiện
  • Tag: AI tự làm / Người giao / Auto (cron)
  • Deadlines + overdue alerts

Phase 1: Sync Engine — Kết nối nguồn dữ liệu

ƯU TIÊN CAO
#ViệcChi tiết
1.1 Schema mới notion_tasks — sync từ Task Tracker DB
notion_content — sync từ Content & Onpage DB
notion_backlinks — sync từ Backlink Tracker DB
notion_weekly_reports — sync từ Weekly Report DB
sheet_content — sync từ Google Sheets (content tự viết)
sync_logs — tracking sync history
1.2 Notion Sync Service Dùng Notion MCP (đã có trong session) hoặc Notion API trực tiếp
Đọc 6 DB → map sang schema local → upsert
Lưu notion_page_id để dedup khi sync lại
1.3 Google Sheets Sync Mở rộng sync hiện tại (đã có cho keywords)
Thêm sheet content tracking → lưu vào sheet_content
Map "File monitor" links → per-project content sheets
1.4 Unified Activity Log activity_log table: source (notion/sheet/local/wp/gsc), action, project_id, timestamp
Ghi mỗi khi sync detect thay đổi

Phase 2: Dashboard V2 UI

CHỨC NĂNG MỚI
#ViệcChi tiết
2.1 Tab Tổng quan (mới) Unified KPIs từ tất cả nguồn
Activity Feed (merge notion_tasks + sheet_content + local events)
Project progress bars (merge strategy + tasks + content)
Weekly report auto-gen
2.2 Tab Nội dung (cải tiến) Merge content từ Notion (AI viết) + Sheets (tự viết) + WP (published)
Thêm source tag, filter by source
Giữ nguyên UI hiện tại, bổ sung data
2.3 Tab SEO (giữ nguyên + bổ sung) Thêm Notion data nếu có (competitor, backlink từ Notion)
2.4 Tab Công việc (mới) Hiển thị Notion Task Tracker
Kanban hoặc table view, filter by project/category/status
Highlight overdue + blocked tasks

Phase 3: Client Report Generator

GIÁ TRỊ CAO
#ViệcChi tiết
3.1 Auto Weekly Report Tổng hợp tuần từ tất cả nguồn → format Weekly Report
Matching cấu trúc Notion (tasks xong, KW lên top, content published, backlinks, lỗi fix)
1-click: copy text / gửi Telegram / xuất HTML đẹp
3.2 Client Report Template HTML report cho khách hàng (per-project)
Gồm: highlights, metrics, content list, next steps
Professional look, logo, brand colors per project
3.3 Telegram Enhanced Bổ sung weekly summary vào bot menu
Alert khi task overdue / content gap
